Notenmeister – Anleitung für Referendarinnen und Referendare

Lokale, verschlüsselte Notenverwaltung nach RSO · Staatliche Realschule Bobingen

Was ist der Notenmeister?

Eine Web-App für Chrome, in der Sie Klassen, Leistungsnachweise und Noten führen. Alle Daten bleiben verschlüsselt auf Ihrem eigenen Rechner; die App baut keine Internetverbindung auf. Die Notenlogik folgt der RSO (ab 01.08.2026) inkl. Gewichtung, Jahresfortgangsnote und Hinweisen, z. B. auf fehlende kleine Nachweise.

1. Installation (einmalig, ca. 10 Minuten)

  1. Node.js (LTS-Version) von nodejs.org installieren.
  2. Quellcode holen: auf github.com/fbinder14/Notenmeister unter Code → Download ZIP herunterladen und entpacken – oder mit Git: git clone https://github.com/fbinder14/Notenmeister.git
  3. Im Terminal in den Ordner wechseln und starten: npm install, danach npm start
  4. In Chrome http://127.0.0.1:4317 öffnen und über das Installieren-Symbol in der Adressleiste als App installieren. Danach startet die App auch ohne Terminal.

Wichtig: Die Adresse samt Port 4317 nicht ändern – Chrome speichert die Daten genau unter dieser Adresse.

2. Erste Schritte

  1. Master-Passwort festlegen. Es gibt keine Wiederherstellung: Passwort vergessen = Daten weg.
  2. Einstellungen → Schuljahre: Schuljahr prüfen (Halbjahreswechsel, Ende).
  3. Klasse anlegen und Namensliste einfügen (aus Excel kopieren oder CSV/XLSX importieren).
  4. In der Klasse einen Unterricht (Fach) hinzufügen. Wochenstunden und Anzahl der Schulaufgaben werden nach Stundentafel vorgeschlagen.
  5. Leistungsnachweis anlegen (Art, Datum, ggf. Höchstpunktzahl und Notenschlüssel), dann Noten per Sammeleingabe erfassen.
  6. Einzelnoten (z. B. Rechenschaftsablage, Unterrichtsbeitrag) über die Schnellerfassung eintragen; für Unterrichtsbeiträge können Sie über mehrere Stunden Beobachtungen sammeln und mit einer Note abschließen.
  7. Am Halbjahresende unter Zeugnis die Noten setzen. Die App macht nur einen Vorschlag – die Entscheidung liegt bei Ihnen.

3. Datenschutz und Sicherung

  • Sicherung regelmäßig exportieren (Einstellungen → Daten und Sicherheit, Datei *.notenmeister, verschlüsselt). Ideal: automatische Sicherung in einen Ordner aktivieren.
  • Die App sperrt sich nach einiger Zeit ohne Eingabe; manuell mit ⌘L bzw. Strg+L.
  • Ausdrucke und PDFs sind nicht verschlüsselt. Die Datenschutzvorgaben der Schule gelten weiterhin.

Den Notenmeister an das eigene Fach anpassen

Beispiel: Sport

Stufe 1: Ohne Programmieren – direkt in der App

Vieles lässt sich unter Einstellungen → Unterricht einstellen. Für Sport zum Beispiel:

  • Fach Sport beim Hinzufügen des Unterrichts wählen; Schulaufgaben auf 0 setzen.
  • Unter Arten von Leistungsnachweisen über Eigene Art fachtypische Nachweise anlegen, z. B. „Leichtathletik“, „Geräteturnen“, „Ballspiel“ – Form praktisch, Kategorie klein, Gewicht nach Absprache mit der Fachschaft.
  • Unter Notenschlüssel eigene Prozentgrenzen anlegen, wenn Sie mit Punkten arbeiten.

Stufe 2: Den Quellcode verändern

Der Notenmeister ist Open Source. Wer mehr möchte (z. B. Leistungstabellen „Weite/Zeit → Note“), arbeitet mit einer eigenen Kopie:

  1. Auf GitHub ein eigenes Konto anlegen und das Repository forken (Schaltfläche Fork). So bleibt das Original unverändert.
  2. Die eigene Kopie klonen, npm install ausführen und mit npm run dev starten. Änderungen erscheinen sofort im Browser.
  3. Ändern, dann prüfen: npm test (Tests) und npm run check (Typprüfung). Zum Schluss wie gewohnt npm start.

Ergänze passende Tests.“ Lassen Sie sich die Änderungen erklären und prüfen Sie sie mit npm test.

Wichtig vor dem Experimentieren

  • Vorher eine Sicherung exportieren. Entwicklungs- und Normalbetrieb nutzen dieselbe Adresse und damit dieselben Daten.
  • Änderungen an Vorbelegungen gelten nur für neu eingerichtete Datenbestände; Bestehendes passen Sie in den Einstellungen an.
  • Keine echten Schülerdaten in Tests, Screenshots oder auf GitHub. Fragen und Ideen gern an Franz Binder.
