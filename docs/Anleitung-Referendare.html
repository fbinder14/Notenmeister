Kapitel 1

Der Notenmeister im Überblick

Eine Web-App für Chrome, in der Sie Klassen, Leistungsnachweise und Noten führen – verschlüsselt, ohne Internetverbindung, mit Notenlogik nach RSO (Fassung ab 01.08.2026).

  • Lokal und verschlüsselt: Alle Daten bleiben auf Ihrem Rechner, geschützt durch ein Master-Passwort.
  • RSO-Logik: Gewichtung großer und kleiner Nachweise, Jahresfortgangsnote, Hinweise z. B. auf fehlende kleine Nachweise oder zu viele Nachweise pro Woche.
  • Offen: Der Quellcode liegt öffentlich auf GitHub (github.com/fbinder14/Notenmeister) und darf an das eigene Fach angepasst werden.
Kapitel 2

Mit KI arbeiten: Werkzeuge und Regeln

ChatGPT und Claude gibt es in zwei Arbeitsweisen. Für dieses Handbuch brauchen Sie beide.

Coding-Agent

2.1Fünf Grundregeln

  1. Keine Schülerdaten an die KI. Niemals Namen, Noten, Ausdrucke, Sicherungsdateien (*.notenmeister) oder Ihr Master-Passwort in einen Chat geben. Für Beispiele immer erfundene Namen verwenden.
  2. Kontext geben. Nennen Sie Betriebssystem, Ziel und was Sie schon versucht haben.
  3. Fehlermeldungen vollständig einfügen – nicht abtippen, nicht zusammenfassen.
  4. Erst planen, dann ändern. Lassen Sie sich vor jeder Code-Änderung einen Plan zeigen und geben Sie ihn frei.
  5. Verstehen, was ausgeführt wird. Fragen Sie nach, wenn ein Befehl unklar ist – besonders bei allem, was löscht oder mit sudo beginnt.
TippBeginnen Sie jedes neue Vorhaben in einem neuen Chat. Lange Verläufe verwirren die KI; ein frischer Chat mit klarem Ziel liefert bessere Antworten.
Kapitel 3

Installation mit KI-Unterstützung

Einmalig, ca. 15 Minuten. Sie brauchen Chrome, Node.js (LTS-Version) und den Quellcode.

3.1Der Weg in Kürze

  1. Node.js (LTS) von nodejs.org installieren.
  2. Quellcode holen: auf GitHub Code → Download ZIP und entpacken – oder git clone https://github.com/fbinder14/Notenmeister.git
  3. Im Terminal (Windows: PowerShell) in den Ordner wechseln: npm install, dann npm start
  4. In Chrome http://127.0.0.1:4317 öffnen und über das Installieren-Symbol in der Adressleiste als App installieren. Danach startet sie auch ohne Terminal. Die Adresse nie ändern – Chrome speichert die Daten genau dort.

Kapitel 4

Erste Schritte in der App

Vom Master-Passwort bis zur Zeugnisnote – in sieben Schritten.

  1. Master-Passwort festlegen. Es gibt keine Wiederherstellung: Passwort vergessen bedeutet Daten verloren.
  2. Einstellungen → Schuljahre: Beginn, Halbjahreswechsel und Ende prüfen.
  3. Klasse anlegen und Namensliste einfügen (aus Excel kopieren oder CSV/XLSX importieren).
  4. In der Klasse einen Unterricht hinzufügen. Wochenstunden und Zahl der Schulaufgaben werden nach Stundentafel vorgeschlagen.
  5. Leistungsnachweis anlegen (Art, Datum, ggf. Höchstpunktzahl und Notenschlüssel) und Noten per Sammeleingabe erfassen.
  6. Einzelnoten wie Rechenschaftsablage oder Unterrichtsbeitrag über die Schnellerfassung eintragen; für Unterrichtsbeiträge lassen sich über mehrere Stunden Beobachtungen sammeln.
  7. Am Halbjahresende unter Zeugnis die Noten setzen. Die App macht nur einen Vorschlag – die Entscheidung liegt bei Ihnen.

4.1Sicherung und Datenschutz

  • Sicherung regelmäßig exportieren (Einstellungen → Daten und Sicherheit). Am besten die automatische Sicherung in einen Ordner aktivieren.
  • Die App sperrt sich nach einiger Zeit ohne Eingabe; manuell mit ⌘L bzw. Strg+L.
  • Ausdrucke und PDFs sind nicht verschlüsselt. Die Datenschutzvorgaben der Schule gelten weiterhin.

4.2Die KI als Lernbegleiter

Prompt 4.1 · Bedienung erklären lassen Chat
Ich nutze die Notenverwaltung „Notenmeister“ (Realschule Bayern, RSO ab 01.08.2026). In der App gibt es Leistungsnachweise der Kategorien „groß“ (Gewicht 2) und „klein“ (Gewicht 1). Erkläre mir an einem erfundenen Beispiel mit drei Schülern, wie daraus eine Jahresfortgangsnote als gewichteter Durchschnitt entsteht.
AchtungKI-Antworten zu Rechtsfragen (RSO, BayEUG) können veraltet oder falsch sein. Verbindlich ist immer der Originaltext der Schulordnung – im Zweifel Seminarlehrkraft oder Schulleitung fragen.
Kapitel 5

Anpassen an das eigene Fach

Am Beispiel Sport: erst die Einstellungen nutzen, dann den Code erweitern.

5.1Stufe 1: Ohne Programmieren

  • Fach Sport wählen, Schulaufgaben auf 0 setzen; unter Notenschlüssel eigene Prozentgrenzen anlegen.
  • Einstellungen → Unterricht → Eigene Art: z. B. „Leichtathletik“, „Geräteturnen“, „Ballspiel“ anlegen (Form praktisch, Kategorie klein, Gewicht nach Absprache mit der Fachschaft).

5.2Stufe 2: Eigene Kopie des Codes

  1. GitHub-Konto anlegen und das Repository forken (Schaltfläche Fork). Das Original bleibt unverändert.
  2. Die eigene Kopie wie in Prompt 3.3 klonen lassen, mit Ihrer Fork-Adresse. Vorher eine Sicherung exportieren: Entwicklungs- und Normalbetrieb teilen sich dieselben Daten.

5.3Der bewährte Ablauf in vier Prompts

Arbeiten Sie in kleinen Schritten: eine Änderung, testen, in der App ausprobieren. Mit „Committe die Änderungen“ sichert der Agent jeden funktionierenden Stand.

Prompt 5.1 · Überblick verschaffen Claude Code / Codex
Lies die README und verschaffe dir einen Überblick über dieses Projekt. Erkläre mir in einfachen Worten, wie es aufgebaut ist und wo die Leistungsnachweisarten, die Notenberechnung und die RSO-Hinweise stehen. Ändere noch nichts.
Prompt 5.2 · Plan für das eigene Fach Claude Code / Codex
Ich unterrichte Sport an einer bayerischen Realschule. Ich möchte: 1. die Leistungsnachweisarten „Leichtathletik“, „Geräteturnen“ und „Ballspiel“ fest einbauen (praktisch, klein, Gewicht 1), 2. dass im Fach Sport kein Hinweis auf fehlende mündliche Noten erscheint. Mach zuerst einen Plan: Welche Dateien änderst du, was genau, und welche Tests ergänzt du? Warte auf meine Freigabe.
Prompt 5.3 · Umsetzen und prüfen Claude Code / Codex
Der Plan passt. Setze ihn um, ergänze Tests und führe „npm test“ und „npm run check“ aus. Erkläre mir danach jede Änderung in zwei, drei Sätzen.
Prompt 5.4 · Größeres Vorhaben: Leistungstabellen Claude Code / Codex
Ich möchte im Sport Messwerte (z. B. Weitsprung in Metern, 50-m-Lauf in Sekunden) per Tabelle in Noten umrechnen, getrennt nach Jahrgangsstufe und Geschlecht. Die Tabellen will ich selbst in den Einstellungen pflegen. Schlage zwei bis drei Lösungswege mit Vor- und Nachteilen vor und orientiere dich an der vorhandenen Notenschlüssel-Logik. Noch nichts programmieren.
