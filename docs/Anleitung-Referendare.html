Kapitel 1

Der Notenmeister im Überblick

Eine Web-App für Chrome, in der Sie Klassen, Leistungsnachweise und Noten führen – verschlüsselt, ohne Internetverbindung, mit Notenlogik nach RSO (Fassung ab 01.08.2026).

  • Lokal und verschlüsselt: Alle Daten bleiben auf Ihrem Rechner, geschützt durch ein Master-Passwort.
  • RSO-Logik: Gewichtung großer und kleiner Nachweise, Jahresfortgangsnote, Hinweise z. B. auf fehlende kleine Nachweise oder zu viele Nachweise pro Woche.
  • Offen: Der Quellcode liegt öffentlich auf GitHub (github.com/fbinder14/Notenmeister) und darf an das eigene Fach angepasst werden.
Kapitel 2

Mit KI arbeiten: Werkzeuge und Regeln

ChatGPT und Claude gibt es in zwei Arbeitsweisen. Für dieses Handbuch brauchen Sie beide.

ArbeitsweiseBeispieleWofür?
Chat
KI erklärt, Sie führen aus		ChatGPT, Claude (normales Chatfenster)Installation Schritt für Schritt, Fehlermeldungen deuten, Fragen zur App
Coding-Agent
KI arbeitet im Projektordner		Claude Code (Claude-App, Bereich „Code“), ChatGPT CodexCode lesen, ändern, testen – also das Anpassen ans eigene Fach

2.1Fünf Grundregeln

  1. Keine Schülerdaten an die KI. Niemals Namen, Noten, Ausdrucke, Sicherungsdateien (*.notenmeister) oder Ihr Master-Passwort in einen Chat geben. Für Beispiele immer erfundene Namen verwenden.
  2. Kontext geben. Nennen Sie Betriebssystem, Ziel und was Sie schon versucht haben.
  3. Fehlermeldungen vollständig einfügen – nicht abtippen, nicht zusammenfassen.
  4. Erst planen, dann ändern. Lassen Sie sich vor jeder Code-Änderung einen Plan zeigen und geben Sie ihn frei.
  5. Verstehen, was ausgeführt wird. Fragen Sie nach, wenn ein Befehl unklar ist – besonders bei allem, was löscht oder mit sudo beginnt.
TippBeginnen Sie jedes neue Vorhaben in einem neuen Chat. Lange Verläufe verwirren die KI; ein frischer Chat mit klarem Ziel liefert bessere Antworten.
Kapitel 3

Installation mit KI-Unterstützung

Einmalig, ca. 15 Minuten. Sie brauchen Chrome, Node.js und Git.

3.1Der Weg in Kürze

  1. Node.js (LTS) von nodejs.org und Git von git-scm.com installieren.
  2. Im Terminal (Windows: PowerShell): git clone https://github.com/fbinder14/Notenmeister.git, cd Notenmeister, npm install, npm start.
  3. In Chrome genau http://127.0.0.1:4317 öffnen und über das Installieren-Symbol in der Adressleiste als App installieren. Danach startet die App auch ohne laufenden Server.
  4. Mac (empfohlen): einmalig npm run autostart:install – der Server startet dann bei jeder Anmeldung von selbst.
WichtigImmer 127.0.0.1:4317 verwenden – nie localhost und nie einen anderen Port. Anderswo erscheint die App leer. „Download ZIP“ statt git clone erlaubt keine Updates.

Kapitel 4

Erste Schritte in der App

Ein Einrichtungsassistent führt durch den Start – danach geht es im Notenbuch weiter.

  1. Master-Passwort festlegen. Es gibt keine Wiederherstellung: Passwort vergessen bedeutet Daten verloren.
  2. Der Einrichtungsassistent fragt nacheinander: Fächer, Schuljahr mit Ferien und Zeugnisterminen (Notenschluss mit dem Terminplan der Schule abgleichen), Klassen und Schülerlisten (aus Excel einfügen oder CSV/XLSX importieren; auf Wunsch eine Beispielklasse), Unterricht und Sicherung. Jeder Schritt lässt sich überspringen und später unter Einstellungen › Unterricht › Einrichtungsassistent nachholen.
  3. Im Unterricht einen Leistungsnachweis anlegen (Art, Datum, ggf. Höchstpunktzahl und Notenschlüssel) und Noten per Sammeleingabe erfassen.
  4. Einzelnoten wie Rechenschaftsablage oder Unterrichtsbeitrag über Mündliche Noten eintragen; für Unterrichtsbeiträge lassen sich über mehrere Stunden Beobachtungen sammeln.
  5. Am Halbjahresende unter Zeugnisnoten die Noten setzen. Die App macht nur einen Vorschlag – die Entscheidung liegt bei Ihnen.

4.1Sicherung und Datenschutz

  • Sicherung regelmäßig exportieren (Einstellungen › Daten und Sicherheit). Am besten die automatische Sicherung in einen Ordner aktivieren.
  • Die App sperrt sich nach einiger Zeit ohne Eingabe; manuell mit ⌘L bzw. Strg+L.
  • Ausdrucke und PDFs sind nicht verschlüsselt. Die Datenschutzvorgaben der Schule gelten weiterhin.

4.2Die KI als Lernbegleiter

Prompt 4.1 · Bedienung erklären lassen Chat
Ich nutze die Notenverwaltung „Notenmeister“ (Realschule Bayern, RSO ab 01.08.2026). In der App gibt es Leistungsnachweise der Kategorien „groß“ (Gewicht 2) und „klein“ (Gewicht 1). Erkläre mir an einem erfundenen Beispiel mit drei Schülern, wie daraus eine Jahresfortgangsnote als gewichteter Durchschnitt entsteht.
AchtungKI-Antworten zu Rechtsfragen (RSO, BayEUG) können veraltet oder falsch sein. Verbindlich ist immer der Originaltext der Schulordnung – im Zweifel Seminarlehrkraft oder Schulleitung fragen.
Kapitel 5

Anpassen an das eigene Fach

Erst prüfen, was schon da ist – dann Einstellungen, dann Code.

5.1Stufe 1: Ohne Programmieren

  • Schon eingebaut: die RSO-Regeln aller Fächer und ein eigenes Profil für Sport („Sport (Jungen)“ / „Sport (Mädchen)“ mit Messwerten und ISB-Tabellen).
  • Einstellungen › Unterricht › Eigene Art: fachtypische Leistungsnachweise (Gewicht nach Absprache mit der Fachschaft).
  • Eigene Notenschlüssel; Schulaufgaben und Wochenstunden unter Unterricht bearbeiten.

5.2Stufe 2: Eigene Kopie des Codes

  1. GitHub-Konto anlegen und das Repository forken (Schaltfläche Fork). Ihre Kopie klonen Sie wie in Prompt 3.3 mit Ihrer Fork-Adresse.
  2. Vor dem Experimentieren: Sicherung exportieren und auf dem Mac npm run autostart:uninstall: npm run dev braucht denselben Port und nutzt dieselben Daten. Danach Autostart wieder einrichten.

5.3Der bewährte Ablauf in vier Prompts

[Fach] und [Wunsch] ersetzen, in kleinen Schritten arbeiten; mit „Committe die Änderungen“ sichert der Agent jeden funktionierenden Stand.

Prompt 5.1 · Überblick verschaffen Claude Code / Codex
Lies die README und verschaffe dir einen Überblick über dieses Projekt. Erkläre mir in einfachen Worten, wie es aufgebaut ist und was es für das Fach [Fach] schon kann. Ändere noch nichts.
Prompt 5.2 · Plan für das eigene Fach Claude Code / Codex
Ich unterrichte [Fach] an einer bayerischen Realschule. Ich möchte: [Wunsch, z. B. eigene Leistungsnachweisarten fest einbauen / einen Hinweis für mein Fach ändern / Teilnoten nach Kriterien]. Prüfe zuerst, ob das schon über die Einstellungen geht. Wenn nicht: Mach einen Plan – welche Dateien änderst du, was genau, welche Tests ergänzt du? Warte auf meine Freigabe.
Prompt 5.3 · Umsetzen und prüfen Claude Code / Codex
Der Plan passt. Setze ihn um, ergänze Tests und führe „npm test“ und „npm run check“ aus. Erkläre mir danach jede Änderung in zwei, drei Sätzen.
Prompt 5.4 · Größeres Vorhaben Claude Code / Codex
Für [Fach] möchte ich [größerer Wunsch]. Orientiere dich daran, wie das Fach Sport eingebaut ist (src/lib/domain/sport.ts). Schlage zwei bis drei Lösungswege mit Vor- und Nachteilen vor. Noch nichts programmieren.
Kapitel 6

Updates einspielen

Neue Versionen erscheinen als Release auf GitHub. Ihre Daten bleiben dabei in Chrome erhalten.

6.1Von neuen Versionen erfahren

Auf github.com/fbinder14/Notenmeister oben Watch › Custom › Releases wählen – dann kommt bei jeder neuen Version eine E-Mail. Was sich geändert hat, steht in CHANGELOG.md. Ihre Version steht unten in den Einstellungen.

6.2In drei Schritten aktualisieren

  1. Sicherung exportieren (Einstellungen › Daten und Sicherheit).
  2. Im Terminal im Notenmeister-Ordner: npm run update – holt die neue Version, baut neu und startet auf dem Mac den Autostart neu. Ohne Autostart danach npm start.
  3. In der App einmal sperren und entsperren – dann ist die neue Version aktiv.
Gut zu wissenBricht npm run update mit dem Hinweis auf eigene Änderungen ab, haben Sie den Code angepasst (Kapitel 5). Dann hilft Prompt 6.2. Wer per ZIP installiert hat, holt den Notenmeister einmal neu mit git clone – die Daten bleiben erhalten.
Prompt 6.1 · Update begleiten Claude Code / Codex
Führe im Notenmeister-Ordner „npm run update“ aus. Wenn es Fehler gibt, erkläre sie mir und schlage eine Lösung vor, bevor du etwas änderst. Fasse mir am Ende zusammen, was laut CHANGELOG.md neu ist.
Prompt 6.2 · Updates in eigene Anpassungen übernehmen Claude Code / Codex
Mein Projekt ist ein Fork von https://github.com/fbinder14/Notenmeister mit eigenen Änderungen. Hole die neueste Version aus dem Original (als Remote „upstream“) und führe sie mit meinen Änderungen zusammen. Zeig mir vorher, was sich ändert, und frag bei Konflikten nach. Danach „npm test“ und „npm run update“ ausführen.
